# Smart Parking — мок-экраны (React Native / Expo)

ШАГ 2: два "телефона" реализованы как один Expo-приложение с выбором режима
при старте — ставишь на два устройства (или два эмулятора), на каждом выбираешь
свою роль.

## Установка и запуск

```bash
cd mobile
npm install
npx expo start
```

Дальше — как обычно с Expo: скани QR из терминала приложением **Expo Go**
(телефон и компьютер с бэкендом должны быть в одной Wi-Fi сети),
либо `npx expo start --android` / `--ios` для эмулятора,
либо `npx expo start --web` для быстрой проверки в браузере.

## Как пользоваться

1. Убедись, что бэкенд запущен и слушает на всех интерфейсах:
   ```bash
   PARKING_BASE_URL=http://<IP-компьютера>:8000 uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```
2. Открой приложение на первом телефоне → введи `<IP-компьютера>:8000` →
   нажми **«🚗 Экран ВЪЕЗДА»**.
3. На втором телефоне — тот же IP → **«🅿️ Экран ВЫЕЗДА»**.
4. Дёргай `/api/sim/entry`, `/api/sim/sensor/{id}`, `/api/sim/exit`, `/api/pay/{id}`
   через Swagger (`/docs`) на бэкенде — экраны обновятся в реальном времени по WebSocket.

Введённый IP сохраняется через `AsyncStorage`, при следующем запуске подставится сам.
Кнопка «Настройки» в углу каждого экрана возвращает на экран выбора IP/режима.

## Что показывает каждый экран

**Экран въезда** (`/ws/entry-display`):
- количество свободных мест отдельно платные/служебные (`X / total`)
- название и цена активного тарифа, бесплатные минуты
- при событии `barrier_open` (gate=entry) — короткий оверлей "Шлагбаум открыт" с номером

**Экран выезда** (`/ws/exit-display`):
- по умолчанию — заглушка "Ожидание автомобиля"
- при событии `exit_bill` — номер, точное время парковки (чч:мм:сс), сумма к оплате
  и QR-код (рисуется напрямую из `qr_code_base64`, который уже прислал бэкенд —
  никакой доп. библиотеки для QR на клиенте не нужно)
- при оплате (`barrier_open` gate=exit → `exit_clear`) — оверлей "Оплата принята"
  и возврат к заглушке ожидания

## Структура

```
mobile/
├── App.tsx                        # переключатель: настройка / въезд / выезд
├── src/
│   ├── types.ts                   # TS-типы WS-событий (зеркалят backend/app/crud.py)
│   ├── hooks/useWebSocket.ts       # подключение + автопереподключение (backoff)
│   ├── components/ConnectionBadge.tsx
│   └── screens/
│       ├── ServerSetupScreen.tsx  # ввод IP + выбор роли
│       ├── EntryDisplayScreen.tsx
│       └── ExitDisplayScreen.tsx
```

Проверено: `npx tsc --noEmit` — 0 ошибок; `npx expo export --platform android` собирает
бандл полностью (589 модулей); `npx expo-doctor` — 19/21 (два оставшихся требуют доступа
к exp.host, недоступному в этой среде разработки — не связано с самим проектом).

Стек: **Expo SDK 57** (react-native 0.86.3, react 19.2.3) — актуальная версия на момент
написания. Если у тебя на телефоне стоит более новый Expo Go и снова появится
"Something went wrong", в 95% случаев это опять рассинхрон SDK: смотри версию
установленного Expo Go (Профиль → About) и сверяй с `"expo"` в `package.json`,
либо просто `npx expo install --check` / `--fix` в проекте — так безопаснее, чем
подбирать версии вручную.
